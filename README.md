# Della Açaí — Biosite

Página de links (bio) da Della Açaí, feita com React + TypeScript + Vite + Tailwind.

## Rodando

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a versão de produção em dist/
```

## Onde editar

- `src/config/store.ts` — links de delivery, WhatsApp, Instagram, avaliação do Google e endereço
- `src/data/menu.ts` — itens do catálogo (cremes, mix, coberturas, frutas)
- `src/assets/logo-della-acai.jpg` — logo (substitua por uma versão em maior resolução se tiver)
- `tailwind.config.js` — paleta de cores e fontes da marca

O mapa usa o embed público do Google Maps, sem precisar de chave de API.
